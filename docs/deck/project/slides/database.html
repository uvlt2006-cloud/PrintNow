Этап 3 · База данных

Цена хранится в позиции заказа

Почему в позиции

Прайс меняется (FR-10), а оплаченный заказ нет: после смены цены итог заказа остался 21 000 сум.

Деньги проверяет база

Итог = печать − скидка + сбор. У заказа только один успешный платёж.

Схема проверена

10 таблиц для PostgreSQL. На тестовых данных отклонены 14 из 14 ошибочных записей.
